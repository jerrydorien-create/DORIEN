# DORIEN
AMIGOSDOISAAC

Esse app é bem simples ele simula o movimento de uma máquina torno cnc

você digita os valores X, Z em cada linha do programa depois de ter digitado todas as linhas é só clicar para simular o grafico

tem um recurso além da interpolação linear que é a interpolação circular, quando você for fazer esse movimento é só inserir junto com X e Z ou só com X, ou só com Z adicione o valor do R que é o raio que vai ativar a interpolação circular

é um app simples, mais de grande importância para quem está começando a aprender operar ou programar tornos CNCs
